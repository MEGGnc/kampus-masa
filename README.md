# Kampüs Masa

Üniversite kütüphaneleri için masa kullanım prototipi.

## Test
- Öğrenci: `2026123456` veya `2026987654`
- OTP: giriş ekranında demo olarak gösterilir
- Masa kodu: `AGU-M-12` gibi `AGU-` + masa kodu

> Bu sürüm prototiptir. Veriler sayfa yenilenince sıfırlanır. Gerçek e-posta, kalıcı veri ve çok kullanıcılı kullanım için Supabase bağlantısı gerekir.
